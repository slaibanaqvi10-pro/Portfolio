## ✨ About

This portfolio highlights my projects, skills, and experience across frontend development, data analysis, and e-commerce operations. Built from scratch with a soft, feminine, and professional design language.

## 🎨 Design

| | |
|---|---|
| **Style** | Elegant, minimal, feminine-professional |
| **Palette** | Dusty Rose `#D98C9B` · Soft Pink `#F4C2C2` · Lavender `#B8A1D9` · Off White `#FFF9F7` · Charcoal `#29242A` |
| **Fonts** | [Playfair Display](https://fonts.google.com/specimen/Playfair+Display) (headings) + [Poppins](https://fonts.google.com/specimen/Poppins) (body) |

## 🛠️ Built With

- **HTML5** — semantic structure
- **CSS3** — custom properties, responsive grid/flexbox, animations
- **Vanilla JavaScript** — no frameworks, no dependencies

## 📌 Features

- 🌗 Light / dark mode toggle (persisted via `localStorage`)
- 📱 Fully responsive — mobile, tablet, and desktop
- 🎬 Scroll-reveal animations with `IntersectionObserver`
- ⬆️ Scroll-to-top button
- 💌 Contact form that opens Gmail with a prefilled message
- ♿ Respects `prefers-reduced-motion` for accessibility

## 📂 Sections

1. **Hero** — introduction & quick actions
2. **About Me** — background, education, and goals
3. **Skills** — frontend, data, business tools, and dev tools
4. **Projects** — Charity Connect, FoodPanda Clone, Calculator, Music Player
5. **Experience** — internship & work history
6. **Resume** — downloadable CV
7. **Contact** — form + social links

## 🚀 Getting Started

Clone the repo and open `index.html` directly in your browser — no build step or dependencies required.

```bash
git clone https://github.com/slaibanaqvi10-pro/laiba-portfolio.git
cd laiba-portfolio
```

Then just open `index.html` in your browser, or serve it locally with any static server (e.g. VS Code Live Server).
